# Вариант 18
Ученый проверяет гипотезу о трех числах. Гипотеза подтверждается, если каждое из трех экспериментально полученных чисел (A, B, C) кратно трем. Запишите условие подтверждения гипотезы.

# Код
```
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

int main() {
	setlocale(LC_CTYPE, "RUS");
	int a, b, c;
	puts("введите три числа:");
	scanf("%d %d %d", &a, &b, &c);

	if ((a % 3 == 0) && (b % 3 == 0) && (c % 3 == 0)) {
		printf("гипотеза подтверждена");
	}
	else {
		printf("гипотеза не подтверждена");
	}
	return 0;
}
```
# Вывод: 
Программа проверяет, кратны ли три введенных пользователем числа числу 3. Если все три числа делятся на 3 без остатка - гипотеза подтверждена, иначе опровергается.
