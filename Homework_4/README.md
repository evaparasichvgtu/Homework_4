# Условие задачи

# Вариант 18
Ученый проверяет гипотезу о трех числах. Гипотеза подтверждается, если каждое из трех экспериментально полученных чисел (A, B, C) кратно трем. Запишите условие подтверждения гипотезы.

# Блок-схема

# Вывод: 
Программа проверяет, кратны ли три введеных пользователем числа числу 3. Если все три числа делятся на 3 без остатка - гипотеза подтверждена, иначе опровергается.
